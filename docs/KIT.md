# Комплект pet-companion: что поддерживается, как подключить, что проверено

Практический комплект текущего выпуска (PL13 в объёме финального спринта 2026-10-20): матрица, API и совместимость, быстрые старты, пример расширения, диагностика, обновление и откат, происхождение ресурсов и лицензии, замеры. Документ собирает существующие материалы и не обещает больше, чем проверено. Версия 1.0 не назначена: критерии стабильного интерфейса и подтверждения платформ (ARCHITECTURE.md § 15) не выполнены. Документ не входит в пакет npm.

## Матрица поддержки

| Часть | Вход | Статус | Где подтверждено |
| --- | --- | --- | --- |
| Ядро | `pet-companion/core`, `/pets`, `/behaviors` | готово | Node: команды, снимок, хранение, определения; установленный архив и типы |
| Веб | `pet-companion` (`mountPet`), `/web` (`mountPetIn`), стили, `manifest.json` | готово | Google Chrome (macOS; CI — Linux): компьютер и ширина телефона, касания, CSP, сайт без сборщика, Vite 8.3.4 |
| React | `pet-companion/react` | готово | React 18.3.1 и 19.3.1, SSR и гидратация, StrictMode |
| Персонаж (минимальный режим, U01) | `pet-companion/character`, `/character-web`, `/character-react` | с 0.3.0 | Node (описание, реакции, тишина, покой, подписка, отключение, два экземпляра), Chrome (два робота, клавиатура, тишина при вводе, «уменьшить движение», фон, отключение и повторное подключение, 320×740; пример на установленном архиве), React 18/19 (SSR, гидратация, StrictMode) |
| iOS | `pet-companion/native`, `/native-sqlite` | **предварительно** | iOS Simulator (Xcode 26.3, iOS 26.3.1, Expo Go 58.0.4) с настоящим вводом XCUITest: питомец, уголок, «Поиграть», «по зову», «Обустроить уголок», редкие сценки, кролик и модель «живая» примера, хранение SQLite, перезапуск, фон, поворот, крупный текст |
| Android | те же | **не проверено в 0.2.4** | эмулятор — только до 0.2.3 (PL10.1–PL10.2.2); жест «Поиграть» не отменяется потерей фокуса окна; новый выпуск на Android решением владельца не проверялся |

Не проверено нигде: Safari, Firefox, браузеры телефонов, физические iPhone и Android-телефоны, VoiceOver и TalkBack вживую, собственные сборки приложений. На нативе редкие сценки — упрощённые ключевые позы с фазами (вход, удержание, выход), не покадровая анимация веба; пример своего питомца и модели на нативе — `examples/expo/extension.mjs` (кролик, «живая»). Подробности — README, «Поддержка платформ».

## API и совместимость

- Публичный интерфейс — README, «Интерфейс» и разделы входов; всё, что закрыто `exports`, — внутреннее. Входы натива — предварительные: их интерфейс может измениться в следующей minor-версии.
- Версии — semver до 1.0 (README, «Версии и обновление»): patch — исправления и совместимые дополнения, minor — несовместимое изменение интерфейса или установки (новые или суженные `peerDependencies`).
- Данные — ключи `v1`, новые поля — только с чтением прежних; записи 0.1.4 читаются без миграции (README, «Хранение»). Вкладка, открытая до обновления, пишет по правилам своей версии до перезагрузки.
- Зависимостей у пакета нет; `react`, `react-native`, `react-native-svg`, `expo-sqlite` — необязательные партнёры только своих входов. Сети ядро не использует.

## Быстрые старты

- **Сайт без сборки:** архив выпуска GitHub → `package/pet/` и `package/manifest.json` → `example.html` (README, «Быстрый старт», «Файлы пакета без сборщика»).
- **npm и сборщик:** `npm install --save-exact pet-companion@<версия>`, `import { mountPet } from 'pet-companion'` и стили `pet-companion/pet.css`, `pet-companion/dog.css` (README, «Подключение из npm»); контейнер — `mountPetIn` (`examples/container.html`); Vite — `examples/vite/`.
- **React:** `PetCompanion`, `usePetState` (`examples/react/`; README, «React и серверный рендер»).
- **Персонаж без комнаты (минимальный режим):** `defineCharacter` + набор `{ character, poses, art, styles }` → `mountCharacterIn(container, { character, kit, name, onActivate })` или `<Character …/>`; продукт подтверждает события `core.react(id, { key, text })` и ведёт свои награды сам (`examples/character/`; README, «Персонаж: минимальный режим»).
- **iOS (Expo):** `examples/expo/` — `npm ci`, `npm run lib` (архив этой библиотеки), Metro и Expo Go в iOS Simulator (README примера, «Запуск в iOS Simulator»); экран — `PetProvider` с `PetView`, `PetCorner`, `PetPlay`, `PetRoom`, хранение `createSqliteStorage`, жизненный цикл `useNativeLifecycle`.

## Пример расширения

`examples/extension/` — третий питомец (кролик: определение, набор веба, стили) и вторая модель поведения (`lively`) только через публичные входы; браузер (`index.html`, `container.html`) и Node (`node.mjs`). `examples/character/` (U01) — персонаж минимального режима (робот: описание без комнаты и кормления, набор, стили, страница стороннего продукта с двумя экземплярами, Node) только через `pet-companion/character` и `/character-web`. Руководство — README, «Питомцы и модели поведения»; правила — CONTRIBUTING, «Новый питомец или модель». На нативе свой питомец требует своего нативного набора (`NativePetKit`): пример — `examples/expo/extension.mjs` (`bunnyNative`: позы, облики, аксессуары, морковка уголка, сценка `hop`; только публичные входы).

## Диагностика

| Признак | Причина и что сделать |
| --- | --- |
| Питомец без стилей или не на месте | стили не подключены или не в порядке перечня: `pet-base.css` (по желанию) → `pet.css` → `dog.css` (README, «Стили»; `manifest.json`, `styles`) |
| 404 на файлах `pet/…` у сайта без сборщика | отдаются не все файлы входа: брать список из `manifest.json` пакета, не вручную (README, «Файлы пакета без сборщика») |
| Нарушения CSP | стили — файлами; у Vite — `assetsInlineLimit: 0` (README; `examples/vite/`) |
| `npm ERESOLVE` при установке | в проекте есть партнёр (`react` и др.) вне диапазона `peerDependencies` (README, «Подключение из npm», «Необязательные партнёры») |
| Команда вернула `{ ok: false }` | код и текст ошибки — `PetError` ядра (README, «Команды и состояние»); `unsupported` — вид или питомец не объявлены отображением |
| «Не всё сохранилось…» | запись хранилища отказала: значение действует до перезапуска, сохранённое не перезаписано; снимок — `getState().save[ключ]` (`status`, `unsaved`) |
| Expo Go: «Could not connect to the server» | Metro на Node 24 без `--dns-result-order=ipv4first` слушает только `[::1]` (README примера) |
| Expo Go показывает старую версию после `npm run lib` | Metro отдал кэш преобразований — перезапуск `npx expo start --clear` (найдено 2026-10-20) |
| Сверка выпуска | `node scripts/release.mjs verify <версия>` — npm, выпуск GitHub, тег, повторная упаковка (docs/RELEASES.md) |

## Обновление и откат

docs/RELEASES.md: гарантии выпуска, три независимых источника контрольных сумм, переход своего проекта проверяемым PR (точная версия, только `package.json` и lock, свои проверки, без автоматического слияния), откат — `git revert` и `npm ci` либо прежняя точная версия. Мобильное приложение получает новую версию только своей сборкой и доставкой.

## Замеры

Это замер одного потребителя, не гарантия для любого сайта.
- **iOS** — функциональные проверки в iOS Simulator; замеры времени и памяти на нативе не проводились.
