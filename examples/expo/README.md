# Мобильный пример PL09 — диагностика хранения и жизненного цикла

Минимальный потребитель `pet-companion` в Expo: настоящий `expo-sqlite` (`pet-companion/native-sqlite`) и настоящие `AppState` / `AccessibilityInfo` (`pet-companion/native`). Экран — обычные `View`, `Text`, `Button`: ни рисунков, ни уголка, ни анимаций (нативное отображение — этап PL10). В пакет не входит. Данные синтетические, база — свой файл `pet-companion-example.db`, пространство имён `expo-example`.

**Статус:** исходники готовы; зависимости не установлены и на устройстве пример **не запускался** (нужно решение владельца, ниже).

## Запуск (после разрешения)

```sh
cd examples/expo
npm ci              # зависимости по package-lock.json (Expo, React Native, expo-sqlite — без --force и --legacy-peer-deps)
npm run lib         # npm pack текущей библиотеки → .lib/, установка архива без записи в package.json и lock
npm start           # Metro в локальной сети (expo start --lan), без туннеля и облачных сборок
```

Телефон и Mac — в одной сети Wi-Fi; в Expo Go (версия для SDK 58) отсканировать QR-код из терминала. `npm run lib` печатает версию, `integrity` и SHA-256 установленного архива — записать в отчёт.

## Что проверить на устройстве

Записать: ОС и её версию, модель, «Expo Go <версия>» или своя сборка, телефон или симулятор (разные отметки).

1. **Загрузка.** Первый запуск: «Хранилище: ready», «Ядро: running, ready», в журнале «start после useNativeLifecycle → ready»; «Перезапуск…: первый запуск».
2. **Имя и движение.** «Имя», затем «Движение»: в журнале `setName: pending` → `cat: pending → saved`, `done → saved`; строка «cat» — `saved, [], []`.
3. **Подтверждённое занятие.** «Подтверждённое занятие»: «Реакция» — `joy`, затем `—`.
4. **Фон и возврат.** Сразу после «Подтверждённого занятия» свернуть приложение и вернуть: в журнале `AppState: background`, `ядро visible: true → false`, затем `AppState: active`, `ядро visible: false → true`; реакция задним числом не играет («Реакция» — `—`). На iPhone — центр уведомлений: `AppState: inactive`, видимость не меняется.
5. **Уменьшение движения.** Включить системное «Уменьшение движения» (iOS: Универсальный доступ → Движение; Android: Специальные возможности → Удалить анимацию) и вернуться: «Движение» — `<выбор владельца> / true / none`; выключить — снова `false`. Выбор владельца не меняется.
6. **Новое ядро.** «Новое ядро»: ✓ «destroy → load → новое ядро», имя и движение — подтверждённые. Два быстрых нажатия подряд: в журнале одна строка «новое ядро после load», «Ядро: running, ready» (результат первого нажатия уничтожен).
7. **Резервирование дня.** «Резервирование дня»: ✓ `shown, затем skip; показов 1` (повторно в тот же день — `skip, затем skip; показов 0`).
8. **Занятый файл.** «Занятый файл»: ✓ `failed через ~1000 мс`; затем «Имя» — несохранённое уходит, `saved`.
9. **Перезапуск с тем же файлом.** Сменить имя и движение, дождаться `saved`, полностью закрыть приложение (смахнуть из переключателя, не просто свернуть), открыть снова: ✓ «Перезапуск с тем же файлом: восстановлено». Это завершение процесса; «Новое ядро» (шаг 6) — перезапуск ядра в том же процессе.

Неподтверждённая правка (`pending`) при закрытии процесса может потеряться — это граница (README библиотеки, «Мобильное хранение»): сохранение обещается только после `saved`.

## Что этот пример не доказывает

Интерфейс питомца, iOS и Android вместе, поворот, безопасные области, несколько процессов (виджеты, App Groups) — не проверяются. Node-проверки библиотеки (`npm run test:native`) доказывают SQL-контракт на `node:sqlite`, но не работу `expo-sqlite`, Metro и нативных API; это делает только запуск на устройстве.

**Владение ядром экрана** (`App.js`): у экрана одно текущее ядро; «Новое ядро» уничтожает прежнее до барьера загрузки, каждое нажатие получает номер — результат более раннего уничтожается; размонтирование уничтожает текущее ядро, а созданное после него — сразу; после размонтирования экран своё состояние не меняет. Это проверяет в Node `test/native-example.test.mjs` библиотеки: исполняет этот `App.js` (только JSX → вызовы React) с настоящими React и хуками, подделкой React Native и управляемым вводом-выводом `diagnostics.mjs` — тоже не устройство.
