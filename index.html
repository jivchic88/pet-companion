A calm cat or dog next to your page

An npm package for websites and React Native apps: the pet reacts to activities your site confirms — lessons, tasks, habits. Plain ES modules and CSS, inline SVG, no dependencies, no network, no build step.

Try it. The pet is already here: on a desktop look at the header and the bottom-right corner, on a phone — the header. Tap the pet to open its corner. Then confirm an activity:

marks: 0, today: 0

Stages open at 3, 9, 18 and 30 marks; the first activity of the day unlocks the treat. Everything is stored in your browser only (namespace demo). The pet's own interface is in Russian — other languages are not supported yet.

Install

npm install pet-companion

Or copy the pet/ folder from the package (or the release archive) to your site and import it without any bundler:

<link rel="stylesheet" href="./pet/pet-base.css" />
<link rel="stylesheet" href="./pet/pet.css" />
<link rel="stylesheet" href="./pet/dog.css" />
<script type="module">
  import { mountPet } from './pet/pet.mjs';

  let marks = 0, today = 0; // your site keeps the score
  const head = document.getElementById('head');
  const pet = mountPet({
    storage: 'mysite',
    places: {
      logo: (el) => head.append(el),            // desktop: header (required)
      top: (el) => head.prepend(el),            // phone: header (required)
      float: (el) => document.body.append(el),  // desktop: bottom-right (optional)
    },
    progress: () => ({ marks, today, limit: 3 }),
  });

  // after your site saved and counted an activity:
  marks += 1; today += 1;
  pet.notify('saved', { key: 'lesson-1', counted: true, first: today === 1 });
</script>

With a bundler: import { mountPet } from 'pet-companion' plus the three CSS imports. React: pet-companion/react. Only a character with reactions, no room or feeding: pet-companion/character-web. React Native (preliminary): pet-companion/native.
